# InvoiceFine Social Media Content Library

Welcome to the **InvoiceFine Social Media Production System**.

This repository section provides an end-to-end framework for planning, scripting, designing, and distributing high-converting social media content for **InvoiceFine** on mobile and desktop.

---

## 🌐 Supported Platforms & Content Formats

| Platform | Primary Formats | Strategic Goal |
|---|---|---|
| **Instagram** | Reels, Educational Carousels, Single-Image Spotlights, Stories | Brand awareness, visual feature discovery, direct app installs |
| **YouTube Shorts** | 15–30s Fast Billing Hacks, Printer Demos, Common Business Mistakes | Search discovery, organic viral reach, feature education |
| **YouTube (Long-form)** | Full Product Tours, Thermal Printer Setup Tutorials, GST Walkthroughs | High-intent customer onboarding, trust-building, technical support |
| **Facebook** | Image Posts, Community Problem/Solution Videos, Milestone Updates | Small business community engagement, local retailer reach |
| **LinkedIn** | Founder/Developer Stories, SME Technology Insights, Release Announcements | Professional authority, B2B partnerships, software distribution |
| **WhatsApp Business** | Status Updates, Feature Broadcast Cards, Direct Video Demonstrations | Direct merchant communication, referral activation, re-engagement |

## 🔄 The 8-Step Content Pipeline

Every piece of content created in this library follows a standardized, high-conversion formula:

```
[1] FEATURE           → Identify specific capability from FEATURE-CONTENT-MATRIX.md
       ↓
[2] CONTENT ANGLE     → Select angle (Problem/Solution, Educational, Speed Demo, Before/After)
       ↓
[3] HOOK              → Grab attention in the first 1–3 seconds or top headline
       ↓
[4] VISUAL CONCEPT    → Define realistic Indian retail/wholesale business context
       ↓
[5] AI PROMPT         → Generate photo/video background using production-ready prompts
       ↓
[6] COMPOSITE UI      → Overlay authentic InvoiceFine screenshot from assets/screenshots/
       ↓
[7] CAPTION & CTA     → Apply localized copy (English / Hinglish / Hindi) with a direct call-to-action
       ↓
[8] HASHTAGS          → Append clutter-free, high-intent topic tags
```

## 📐 Recommended Image & Video Dimensions

| Format | Recommended Dimensions | Aspect Ratio | Primary Use Case |
|---|---|---|---|
| **Instagram / Facebook Portrait** | 1080 × 1350 px | 4:5 | Feed Single Posts & Carousels (Maximum screen real estate) |
| **Square Post** | 1080 × 1080 px | 1:1 | Universal Social Posts, LinkedIn Updates |
| **Reels & Shorts / Stories** | 1080 × 1920 px | 9:16 | Full-screen vertical video for Instagram Reels, YouTube Shorts |
| **YouTube Thumbnail** | 1280 × 720 px | 16:9 | Video covers and horizontal banners |
| **LinkedIn Document / Slide** | 1200 × 1500 px | 4:5 | PDF Slide Carousels |

*Note: Dimensions are based on standard platform guidelines and may be adjusted to match platform updates.*

## 🛡️ Content Integrity Guidelines

1. **Zero Fake Testimonials**: Never publish fabricated merchant reviews, fictional store names with fake quotes, or synthetic user numbers.
2. **Zero Fake Statistics**: Never claim unsubstantiated metrics like "Guaranteed 40% profit increase" or "Government certified".
3. **No Hallucinated UI**: Always composite real InvoiceFine application screenshots from [`assets/screenshots/`](../assets/screenshots/) or real screen recordings.
4. **Natural Localized Voice**: Write marketing copy that speaks respectfully to Indian merchants, shopkeepers, and independent business owners.
