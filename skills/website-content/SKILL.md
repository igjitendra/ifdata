# InvoiceFine Website Content & Landing Page Skill

## Purpose
Produce clear, persuasive, user-facing website sections, landing page hero blocks, feature showcases, download guides, and FAQs for the InvoiceFine public web portal.

## When to Use
- Writing or updating landing page copy for mobile and desktop versions.
- Structuring product feature pages and technical specification grids.
- Writing frequently asked questions (FAQs) and customer support guides.

## Inputs
- Web page target (Homepage, Features Page, Download Page, FAQ).
- Target audience (Mobile merchant or Desktop POS retailer).

## Workflow
1. **Hero Section**: Craft a bold headline, supporting value proposition, primary download CTA buttons (Google Play / Linux AppImage), and device mockup preview.
2. **Feature Grid**: Organize confirmed features into 4–6 distinct visual cards with icons, 2-line descriptions, and matching screenshot references.
3. **Hardware Compatibility Bar**: Showcase supported printers (58mm, 80mm, Bluetooth, USB, Wi-Fi) and barcode scanners.
4. **FAQ Section**: Answer the top 5 practical merchant questions (internet requirement, pricing, backup, data privacy).

## Rules
- Focus on conversion: clear, prominent download and install CTAs.
- Keep technical jargon minimal; explain technology through business outcomes.
- Link directly to verified public assets and downloads (e.g., `downloads/` directory).

## Output Format
- **PAGE TITLE & META DESCRIPTION**
- **HERO BLOCK**: Headline, Subheadline, CTA Buttons, Hero Image Asset Reference.
- **FEATURE SHOWCASE CARDS**: 4–6 structured feature blocks.
- **FAQ ACCORDION**: Questions and concise, reassuring answers.

## Examples
```text
HERO SECTION:
Headline: Modern Billing & Khata for Indian Retailers
Subheadline: Generate GST invoices, manage stock, print thermal receipts, and track customer dues. Runs 100% offline on Android and Linux.
Primary CTA: [Download on Google Play]
Secondary CTA: [Download for Linux Desktop]
Hero Visual: Smartphone and desktop laptop mockups displaying real InvoiceFine dashboards.

FAQ EXAMPLE:
Q: Does InvoiceFine require an active internet connection to create bills?
A: No. InvoiceFine is built completely offline-first. You can create invoices, print thermal receipts, and check inventory with zero internet. Your data is stored safely on your own device.
```

## Quality Checklist
- [ ] Meta title and description formatted for web SEO.
- [ ] Conversion CTA prominently positioned.
- [ ] Answers address real merchant friction (offline use, data privacy).
- [ ] Visual references point to real asset files.
